# ETS2 Save Edit Tool  
一款现代且功能强大的存档编辑器，适用于 欧洲卡车模拟2 (欧卡2) 以及后来的 美洲卡车模拟 (美卡)。  
当前状态：**0.1 Alpha（开发中）**

---

## 概述
该工具读取 ETS2 存档，显示数据，允许编辑，并将更改安全地写回。  
暂不可用功能将显示为“即将推出”。

更新通过 GitHub Releases 内置的自动更新程序进行推送。

## 🚀 v0.2.0 版本即将推出
我们目前正在进行一项重大的用户界面/用户体验改造，以使用户体验更快、更现代化。

- **现代化用户界面：**简洁、结构化的布局，采用全新的基于标签的导航。
- **主题支持：** 您可以从三个精选主题中选择：*霓虹之夜*、*暗黑专业版*和*纯净之光*。
- **性能：**优化了核心逻辑，带来更流畅的操作体验和更快的加载速度。
- **生活质量：**改进了模态框处理、上下文帮助文本和状态指示器。
- **社区关注：** 集成了更新检查器和直接的 GitHub 反馈链接。

## 安装与更新
以 MSI 安装程序形式提供。  
自动更新程序会检查 GitHub Releases 是否有新版本。

只有已发布的版本才会触发更新。  
常规提交**不会**生成更新通知。
